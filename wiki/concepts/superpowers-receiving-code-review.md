# receiving-code-review

"Use when receiving code review feedback, before implementing suggestions, especially if feedback seems unclear or technically questionable - requires technical rigor and verification, not performative agreement or blind implementation."

Cómo procesar feedback de revisión de código: exige rigor técnico y verificación antes de aplicar una sugerencia, en vez de aceptación automática o implementación ciega.

Ninguna relación con los subagentes del TFM — el equivalente funcional en este proyecto (revisión de un capítulo redactado) lo cubre [[tfm-subagente-revisor-calidad]] con su propio checklist, no esta skill. Ver [[tfm-skills]].
