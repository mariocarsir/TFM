# defuddle

Planifica, y con consentimiento explícito de red usa, un limpiador externo opcional (Defuddle) para extraer páginas web tipo artículo como Markdown legible, sin publicidad ni navegación. Sirve como paso previo a [[claude-obsidian-wiki-ingest]] cuando la fuente es una URL.

Se invoca con `/claude-obsidian:defuddle`.
