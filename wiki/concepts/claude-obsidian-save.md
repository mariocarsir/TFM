# save

Guarda una respuesta, decisión, insight o resumen de sesión seleccionado explícitamente por el usuario, como una única transacción revisada (nota + índice + log + hot cache). Diseñada explícitamente para NO ser una grabadora automática de transcripciones: solo actúa cuando se pide, nunca al cerrar una sesión.

Se invoca con `/claude-obsidian:save`.
