# finishing-a-development-branch

"Use when implementation is complete, all tests pass, and you need to decide how to integrate the work."

Ayuda a decidir cómo integrar una rama de desarrollo ya terminada y con tests en verde (fusionar, abrir PR, descartar) — el paso de cierre tras completar una implementación.

Ninguna relación con los subagentes del TFM — el TFM no tiene un ciclo de ramas de desarrollo de software al que aplicar esto. Ver [[tfm-skills]].
