# writing-skills

"Use when creating new skills, editing existing skills, or verifying skills work before deployment."

Guía para crear skills nuevas, editar las existentes o verificar que funcionan antes de desplegarlas — la skill que se usaría para escribir o ajustar, por ejemplo, `humanizer` o `auditor`.

Ninguna relación con los subagentes del TFM. Ver [[tfm-skills]].
