# brainstorming

"You MUST use this before any creative work - creating features, building components, adding functionality, or modifying behavior. Explores user intent, requirements and design before implementation."

Se antepone a cualquier skill de implementación cuando la tarea es de diseño abierto ("vamos a construir X"): explora intención, requisitos y diseño antes de escribir una sola línea.

Ninguna relación con los subagentes del TFM — se invoca desde la conversación principal antes de delegar, no dentro de un subagente. Ver [[tfm-skills]].
