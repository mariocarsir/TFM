# Capturas de pantalla de trabajo en PVsyst

Formato de nombre obligatorio: `AAAA-MM-DD_HHMM.png` (ejemplo: `2026-08-06_1902.png` para una captura del 6 de agosto de 2026 a las 19:02).

El agente `piloto-pvsyst` siempre responde sobre la captura con el timestamp más reciente de esta carpeta. Sin ese formato no puede identificar cuál es la última sin ambigüedad.
